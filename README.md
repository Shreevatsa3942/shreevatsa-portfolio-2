# 🚀 Shreevatsa's Portfolio v2

A modern, responsive portfolio website inspired by [sameerchachiya.site](https://sameerchachiya.site/). Built with vanilla HTML, CSS, and JavaScript — no frameworks needed.

## ✨ Features

- **Dark/Light Mode** — System preference detection with manual toggle
- **Responsive Design** — Looks great on desktop, tablet, and mobile
- **Smooth Animations** — Scroll-based reveal, typing effect, floating profile image
- **Section-based Navigation** — Active link tracking on scroll
- **Scroll Progress Bar** — Visual progress indicator
- **Modern Design** — Clean cards, timeline layout, gradient backgrounds

## 📦 Sections

| Section | Description |
|---------|-------------|
| **Home** | Hero section with profile image, intro, and social links |
| **Experience** | Timeline-based professional experience (Cardinal Health, Bazaarvoice) |
| **Skills** | 4-column grid with categorized technical skills |
| **Projects** | Project cards with images, descriptions, and GitHub links |
| **Education** | Education timeline |
| **Contact** | Email contact card |

## 🛠️ Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — Theme toggle, scroll handling, IntersectionObserver
- **Google Fonts** — Inter typeface

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Shreevatsa3942/shreevatsa-portfolio-2.git
cd shreevatsa-portfolio-2
```

2. Open `index.html` in a browser, or serve locally:
```bash
python3 -m http.server 8080
```

3. Visit [http://localhost:8080](http://localhost:8080)
